Sources and parameter interpretation

2 s as the baseline: UK Highway Code Rule 126 recommends at least 2 s on high-speed roads under specified conditions; this is guidance, not a universal measured mean. UK Highway Code.

Traffic-flow basis: Newell (2002), A simplified car-following theory: a lower order model. Our s = s₀ + vT and triangular FD are a steady-state lecture approximation related to this family; this app does not implement Newell's delayed-trajectory translation exactly. Newell, 2002.

IDM comparison: a commonly used IDM example assigns T = 1.5 s to cars, but T is not universally fixed. IDM reference.

HCM interpretation: 1,900 passenger cars/h/lane corresponds to approximately 1.89 s saturation discharge headway at ideal signalized approaches, not a universal 1.89 s cruising time gap. FHWA / HCM explanation.

For an interpretable T-only sensitivity check, select Matched dynamics and the Original policy. The T analysis does not modify the current live headway setting.
